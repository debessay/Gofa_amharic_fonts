# Aklilu Debessay

> ሰላም፣ ነጻ የግዕዝ እና የአማርኛ ቅርጸ-ቁምፊዎችን አዘጋጃለሁ።

Hello. I design free Ge'ez and Amharic fonts and release them under the SIL Open Font License 1.1. I also work as a building maintenance technician.

## Fonts

**[Geez_Gofa_C](https://github.com/debessay/Gofa_amharic_fonts)** — a Ge'ez and Amharic typeface in four styles: normal, condensed, expanded, and oblique. OTF, TTF, and WOFF2.  
[Specimen and downloads](https://debessay.github.io/Gofa_amharic_fonts/)

**[Geez_Gofa_mono_C](https://github.com/debessay/Geez_monospace_font)** — a monospace font for Ge'ez, Amharic, and Latin, with 578 characters.  
[Download v1.0](https://github.com/debessay/Geez_monospace_font/releases/tag/V1.0)
